sistemizde backend kısmını çalıştırmak için teerminalden backend klasörüne "cd backend " koduyla giriş yaptıktan sonra ./mvnw spring-boot:run komutunu kullanabilirsiniz.
backend terminali açıkkken frontend kısmı için de yeni terminal açarak "cd frontend " kodu ile giriş yaptıktan sonra "npm install" ile bir seferlik react çalışması için gereken
dosyayı kurduktan sonra "npm start"yaparak portumuzu açmış oluyoruz.Bir kere dosya kurulduktan sonra "npm install"komutunu tekrar kullanmanıza gerek yoktur.
